## Ручная проверка студенткой — результаты

В ветке `feature/delete-card` из папки client запустить `npm ci`, затем в разных терминалах `npm run server` и `npm run dev`. Открыть адрес Vite. Создать отдельные тестовые карточки; исходные учебные записи удалять не нужно.

1. Пустое поле и одни пробелы: «Добавить» неактивна. Обычный текст добавляет карточку; поле очищается. После F5 нет новых пустых записей.
2. У выполненной и невыполненной карточки есть «Удалить». Действие доступно через Tab и Enter.
3. Нажать удаление и отменить подтверждение: карточка остаётся, в Network нет DELETE.
4. Подтвердить удаление тестовой карточки: она исчезает без F5, остальные остаются. После F5 удалённая карточка не возвращается.
5. Для ошибки оставить страницу открытой, остановить json-server, подтвердить удаление другой тестовой карточки: она остаётся, появляется ошибка. Запустить сервер и повторить: удаление проходит.

Для проверки сохранения используется копия тестовых данных; API-тест не менял client/db.json в репозитории. JSDOM проверяет поведение React, но не визуальное отображение и не заменяет личную проверку в браузере.
